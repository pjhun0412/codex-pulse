# Codex Pulse v0.1.1

작업표시줄 위젯의 도킹 방식과 표시·입력을 개선한 버전입니다.

## 변경 사항

- 위젯을 Explorer 작업표시줄의 실제 자식 창으로 연결하고, 위젯 자체의 최상위 강제를 제거했습니다.
- 도킹 후 위젯이 보이지 않거나 좌우클릭에 반응하지 않던 문제를 수정했습니다.
- 메뉴·상세창이 주변을 덮을 때 배경색이 바뀌지 않도록 색상 샘플링을 보완했습니다.
- 작업표시줄 위젯 폭을 306px에서 248px로 줄였습니다.
- 디버그 EXE도 별도 CMD 창 없이 실행하도록 수정했습니다.

## 설치

기존 Codex Pulse를 종료한 뒤 `Codex.Pulse_0.1.1_x64-setup.exe`를 실행하세요.
Codex 사용량을 읽으려면 Codex Desktop이 설치되어 있고 로그인되어 있어야 합니다.
설치 파일은 디지털 서명되지 않았습니다.
